# Changelog

Generated by the release workflow.


#### [v0.2.0](https://github.com/saforem2/wandb-tui/releases/tag/v0.2.0)

> 23 August 2026

The interactive TUI is rebuilt on [Textual](https://textual.textualize.io).
Runs can be grouped into a collapsible tree by any config keys, charts are
real widgets with full-screen zoom, and the whole view follows your
terminal's light/dark theme.

**Grouping and filtering**

- `G` groups runs into a nested tree by one or more config keys, with a run
  count per node and <kbd>Enter</kbd> to collapse. Also `--group-by`, which
  prints the tree in `--once` and nests a `groups` array in `--json`.
- `f` filters runs by a config expression (`lr>=0.001 model~llama`), with
  tab-completion for keys and values. Also `--filter`.
- `/` searches metric names; wrap the query in `/slashes/` for a regex.

**Charts**

- Chart tiles are focusable widgets; <kbd>Enter</kbd> opens one full-screen
  with zoom, pan, per-run focus and a log/linear toggle.
- `X` cycles the x-axis: Step, relative process or wall time, wall clock, or
  `n_tokens_seen`.
- `M` cycles the plotext marker (hd / braille / fhd / dot / sd).
- <kbd>Space</kbd> shows or hides a run — or a whole group — in the charts.

**Everything else**

- Follows the terminal's light/dark background automatically, with a light
  theme that keeps the page white.
- Loads 100 runs by default: one cheap metadata query, then history only for
  runs that survive the filter, cached on disk and re-read in 0.01–0.08s.
- `h` hides the header to reclaim the rows; `x` reverses sort (group order
  when grouped); run names in the legend link to wandb.ai.

**Deprecation**

- `--group` filtered *metric* groups, not runs, which became confusing once
  run grouping existed. It is now `--metric-group`. The old spelling still
  works and warns on stderr.
